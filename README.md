# OVD: On-policy Verbal Distillation

This repository contains the code for the two settings used in the OVD project:

- `OVD_math/`: mathematical reasoning experiments.
- `OVD_Web/`: web question-answering experiments.

Each subproject has its own installation instructions, dependencies, launch scripts, and license. Start with the README in the subproject you plan to use:

- [Math](OVD_math/README.md)
- [Web](OVD_Web/README.md)

The Web Query Reject-5 launch script is `OVD_Web/scripts/train_query_reject5.sh`. The Math and Web environments are separate; install and run them independently.
